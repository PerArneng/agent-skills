# Orca project icon

Produce a small, recognisable icon that represents *this* project, in the
current repo:

```
docs/icon/
├── icon.svg          # source of truth, committed
├── render.sh         # renders icon.svg -> icon-<N>x<N>.png, committed
└── icon-64x64.png    # generated, git-ignored
```

## 1. Understand the project first

The icon is only good if it says something about the project. Before
drawing, skim the README, AGENTS.md/CLAUDE.md, the package manifest and the
top-level layout to find the one core idea (e.g. "manages a LAN" → router
with connected nodes; "home automation" → house + signal; "CLI tool" →
prompt glyph). Pick a single metaphor; combining two ideas makes the icon
unreadable at 64 px. If the project is genuinely ambiguous, propose two
metaphors in one line and pick the stronger one rather than stalling.

## 2. Design rules (why: it is shown at 16–64 px in a sidebar)

- `viewBox="0 0 512 512"`, `width`/`height` 512, with a `<title>` naming the project.
- An app-icon tile: rounded square (`x=16 y=16 w=480 h=480 rx≈104`) with a
  solid fill or a gentle two-stop vertical gradient. The tile gives the icon
  a consistent silhouette next to other projects' icons.
- Flat 2D geometry only: rect, circle, path. No text (unreadable at 64 px
  and doesn't survive renderers without the font), no filters, blur, shadows,
  masks or external images — renderers differ on these.
- 2–3 colours: a dark tile, one accent colour, one light colour. Ensure
  strong contrast between glyph and tile.
- Strokes ≥ 20 units and gaps ≥ 24 units at 512 scale (≈ 2.5–3 px at 64 px)
  so details don't blur into each other. Keep the glyph within ~64 units of
  the tile edge.
- Use `stroke-linecap="round"` and rounded corners for a professional,
  consistent feel.

## 3. Write the files

1. `mkdir -p docs/icon` and write `docs/icon/icon.svg`.
2. Copy the bundled renderer: `cp <this-skill-dir>/scripts/render.sh docs/icon/render.sh && chmod +x docs/icon/render.sh`.
   It tries rsvg-convert, inkscape, ImageMagick, then falls back to
   `uv run --with resvg-py` so it works without system packages. It takes an
   optional size argument: `./render.sh 256` → `icon-256x256.png`.
3. Run `docs/icon/render.sh`.
4. If the repo is a git repo, add `docs/icon/*.png` to `.gitignore` (with a
   comment saying it is regenerated by render.sh) unless already covered.

## 4. Check the render — don't skip

Read `docs/icon/icon-64x64.png` with the Read tool and actually look at it.
Ask: can I tell what it is at this size? Are any lines merging or any
elements too small? If so, simplify (fewer elements, thicker strokes, larger
shapes) and re-render. Iterate until it reads clearly.

## 5. Import icons and friendly names into Orca

Orca stores uploaded repo icons as base64 data URIs (`repoIcon.src`, `source: "upload"`) and project display names (`displayName`) inside both the `repos` and `projects` documents of `profile-state.db`:

- **macOS:** `~/Library/Application Support/orca/profiles/<profile>/profile-state.db`
- **Linux:** `~/.config/orca/profiles/<profile>/profile-state.db`

Use the bundled `uv` single-file importer script to embed `docs/icon/icon-64x64.png` and/or set friendly UI display names:

```bash
# Quit Orca first so its in-memory state doesn't overwrite the DB
<this-skill-dir>/scripts/import-to-orca.py --dry-run
<this-skill-dir>/scripts/import-to-orca.py --render --friendly-names
<this-skill-dir>/scripts/import-to-orca.py --no-icons --rename video-blideo="Video Blideo" --rename homeassistant="Home Assistant"
<this-skill-dir>/scripts/import-to-orca.py --repo .
```

The script automatically backs up `profile-state.db`, updates `content_hash` and `revision` for both `repos` and `projects`, and refuses to write if Orca is still running. Reopen Orca afterwards to see the updated icons and names.

## 6. Report to the user

Briefly describe the metaphor and colours, list the files, and mention:

- **Orca stores a copy, not a path.** After changing the SVG and re-rendering, re-run `scripts/import-to-orca.py` (with Orca quit) or re-upload the PNG in Orca's UI.
- Don't commit unless asked.
